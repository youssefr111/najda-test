header unless marked \emph{public}. The access column gives the minimum authorisation; ownership and scope
checks are applied again inside the services (\cref{sec:authorisation}). Abbreviations: A\,=\,Admin,
SA\,=\,Super Admin, D\,=\,Dispatcher, FM\,=\,Facility Manager, LEAD\,=\,the unit's accountable operator.
